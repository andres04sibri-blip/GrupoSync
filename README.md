# Gestor Móvil de Materiales y Tareas en Grupo (GrupoSync)

## Problema
Los estudiantes que realizan trabajos en equipo suelen perder el control de quién compra o lleva los materiales específicos, generando olvidos de última hora y discusiones antes de la entrega.

## Solución
La aplicación permitirá crear una lista compartida de tareas y materiales asignados a cada integrante del grupo, mostrando de forma visual quién ya cumplió con su parte y quién tiene pendientes.

## Objetivos
- Permitir la adición y eliminación exitosa de ítems en la lista.
- Mostrar el cálculo automático del porcentaje según los ítems marcados.
- Conservar los ítems registrados al reiniciar la aplicación.

## Habilidades
- Desarrollo de aplicaciones multiplataforma con React Native y Expo.
- Estructuración de componentes reutilizables y manejo de estados.
- Diseño de interfaces intuitivas y modernas para dispositivos móviles.

## Alcance inicial
Pantalla para agregar y eliminar tareas o materiales de la lista.
Casilla de verificación (checkbox) para marcar elementos completados.
Contador rápido del porcentaje total de avance del proyecto.

## Restricciones
- El almacenamiento de los datos será local en la memoria del dispositivo.
- No incluirá sincronización en la nube en esta primera fase.
